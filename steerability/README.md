# I. Steerability

Understanding revealed preference and steerability in AI agents.

This first part examines recorded model choices in moral dilemmas, compares aggregate model preferences with human reference preferences, and tests how explicit instructions shift those choices. It also extends preference measurement to everyday moral dilemmas.

[Explore the experiment, data, and everyday dilemmas](https://brookesmilen.com/mas-research/).

The existing website, recorded responses, preference summaries, and figures remain at the repository root so their published paths continue to work.
